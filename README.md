# Обоснование выбора коллекций в трекере книг (`tracker.py`)

В трекере используется list (history) для хранения динамического списка книг с сохранением хронологического порядка их добавления и возможностью фильтрации записей. Каждая отдельная книга представлена через неизменяемый tuple (book_id, title, author, year, genre), что фиксирует структуру записи и защищает её поля от случайной мутации. Для мгновенного поиска книги по идентификатору и проверки дубликатов за время $O(1)$ применяется dict (by_id), где ключом выступает хешируемый book_id. Поля authors и genres реализованы через set, так как для сводного отчета важна только уникальность значений без дубликатов.
